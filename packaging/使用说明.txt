﻿席间索 (Table Canon) v0.1.0
========================================

跑团(桌上角色扮演)资料席间检索工具：把模组/自设资料导入本地库，
DM 在席间随口一问（比如「独眼酒保给过什么任务」），5 秒内定位原文条目。
查询完全本地离线，不上传任何数据。

【快速开始】
1. 双击「安装席间索.bat」→ 回车用默认目录，或输入你想装的目录
2. 安装完成后从桌面/开始菜单打开「席间索」
3. 第一次用：点「试用样例」自动建库并导入示例，试试搜「独眼酒保」
4. 导入自己的资料：「新建库」→「导入 Word / 导入文件夹」
   支持 .docx / .md / .txt / .rtf / .html（不支持旧版 .doc 和 PDF）

【AI 拆条（可选）】
导入时勾选「导入时 LLM 拆条」，长章节会自动切成设定条目。
需要在程序同目录的 llmconfig.toml 里配置一个 OpenAI 兼容接口
（复制 llmconfig.example.toml 为 llmconfig.toml 修改即可）。
不配置也完全能用：内置规则拆条，查询不受影响。
注意：拆条建议用便宜的小模型，推理大模型会拖慢导入。

【语义检索（已内置，无需联网）】
程序自带中文语义模型（bge-small-zh，约 24MB，已在包内）。
- 用大白话也能搜到没有共同词的条目，比如搜「想找个地方喝一杯」能命中「酒馆」
- 导入时自动计算向量，无需任何操作；纯语义命中的结果卡片带「语义」角标
- 底栏右下角显示状态：语义 · 开 / 准备中 / 不可用 / 未装模型
- 首次启动加载模型约几秒，期间检索自动用关键词，不影响出结果
- 不想要语义：删掉安装目录的 models 文件夹与 onnxruntime.dll 即可

【你的数据在哪】
- 战役库(.tcs)：你导入时自己选的位置，卸载不删除
- 配置与缓存：%APPDATA%\table-canon
- 安装目录：默认 %LOCALAPPDATA%\Programs\TableCanon（可自定义）

【卸载】
- Windows 设置 → 应用 → 找到「席间索」→ 卸载
- 或运行安装目录下的「卸载席间索.bat」
- 两者都只删程序，不删你的战役库和资料

【常见问题】
- 首次运行如弹出 SmartScreen 蓝色提示：点「更多信息」→「仍要运行」
  （本程序未做代码签名，属正常现象）
- 中文显示依赖系统微软雅黑字体，中文版 Windows 自带
- 杀毒软件若误报，加入信任即可（程序完全本地运行，仅拆条时按你的配置访问 LLM 接口）
